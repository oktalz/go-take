gotake player examples

Each player below plays demo.take, which has two markers: intro and tests.

1. Embed with data attributes

One script tag and one element. The player starts when the page loads and plays in a loop.

<script src="gotake-player.js"></script>
<div data-gotake-src="demo.take" data-autoplay data-loop data-idle-time-limit="2"></div>

2. Chapters with start and stop markers

The same recording embedded twice, one chapter each. data-start-at and data-stop-at take a marker label or seconds. Playback pauses at the stop marker. Press play to continue past it.

intro → tests
tests → end
<div data-gotake-src="demo.take" data-start-at="intro" data-stop-at="tests"></div>
<div data-gotake-src="demo.take" data-start-at="tests" data-poster="tests"></div>

3. Control it from JavaScript

GoTakePlayer.create returns a player you can drive with your own buttons. Its events are logged below. 

const p = await GoTakePlayer.create('#api-player', 'demo.take', { idleTimeLimit: 1 });
p.on('marker', m => log('marker ' + m.label));
p.seek(p.resolveTime('tests'));
p.setSpeed(2);
p.play();
